# Unitree Z1 Water Pouring Demo
> [!IMPORTANT]
> Requires MuJoCo 2.3.3 or later.
## Overview
This project demonstrates a **Unitree Z1 manipulator** performing a water pouring task in a MuJoCo simulation. The robot arm grasps a bottle and pours liquid (simulated via particle physics or fluid dynamics approximations) into a glass.
<p float="left">
  <img src="z1_pouring.png" width="400" alt="Z1 Arm Pouring Water">
</p>
## Features
- **Robot Model:** Unitree Z1 manipulator (MJCF format).
- **Task:** Pick and place / pouring motion planning.
- **Simulation:** Fluid interaction between a bottle and a glass.
